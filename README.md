# Club_Squirrel
## Description:
Squirrel Club is a social connecting game where you can be a squirrel and meet people or hangout with friends. 
## Agile Planning:
| User Story | Status |
| ----------- | ----------- |
| As a user, I want a menu, so I can navigate the game. | Completed |
| As a user, I want a login, so I can save data and better connect with my friends. | Completed |
| As a user, I want a registration page, so I can create an account and start playing the game. | Completed |
| As a user, I want a settings, so I can customize my game experience. | Completed |
| As a user, I want a game screen with connection to other players, so I can play the game. | In progress |
| As a developer, I want a back-end, so each page connects data to work together. | In progress |
| As a user, I want a help page, so I can solve problems I may have with the website. | Completed |
